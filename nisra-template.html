Text content (h2)

Web font is Roboto with Arial then sans serif as fallbacks. Text colour is #222222. Line height is 1.5 to give adequate spacing between lines.

Headings (h3)

Headings are in the same text colour and sizes are set in the CSS. None are bold.

Body text (h4)

Body text is 18px for readability.

Hyperlinks are underlined and in blue. On hover, the thickness of the underline increases to 3px.

By default, hyperlinks should open in the same tab. If leaving the page would interrupt a user's session or cause them to lose their work, open in a new tab and use this symbol.

Buttons
